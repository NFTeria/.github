# NFTeria organization files

This repository holds the organization-level files GitHub reads for the **NFTeria**
organization. It contains no product code.

**This repository is public.** Everything in it is readable by anyone.

| File | What it is |
|---|---|
| `profile/README.md` | The page shown at [github.com/NFTeria](https://github.com/NFTeria) |
| `profile/privacy.md` | The privacy statement linked from that page |
| `SECURITY.md` | How to report a vulnerability |
| `.github/workflows/` | The workflows that run in this repository |

NFTeria's product is **UNICA**, an MIT-licensed settlement hook and modular integration
layer for Uniswap v4, testnet only. Its code, tests, deployment records and
documentation are in [github.com/NFTeria/UNICA](https://github.com/NFTeria/UNICA).
